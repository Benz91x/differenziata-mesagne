# Differenziata Mesagne

Cosa si porta fuori oggi, ieri e domani a Mesagne: il calendario della raccolta differenziata porta a porta (organico, plastica, vetro e metalli, carta, secco residuo), giorno per giorno.

**Apri l'app:** https://benz91x.github.io/differenziata-mesagne/

L'app funziona anche offline e si può installare sul telefono («Aggiungi a schermata Home»).

## Contenuto

- `index.html` — l'app (HTML, CSS e JavaScript in un unico file)
- `sw.js` — service worker per l'uso offline
- `manifest.webmanifest`, `icons/`, `favicon.ico` — icone e dati per l'installazione come app
- `assets/logo.png` — logo
- `sitemap.xml` — mappa del sito per i motori di ricerca

Il sito è pubblicato con GitHub Pages dal ramo `main`.
